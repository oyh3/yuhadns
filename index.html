빠르고 안전한
프라이빗 DNS-over-HTTPS

광고와 트래커는 강력하게 차단하고, 다중 업스트림 병렬 쿼리로 가장 빠른 DNS 응답 속도를 경험하세요.

https://your-domain/dns-query

주요 기능

보안, 속도, 호환성을 모두 충족하는 차세대 DNS 솔루션입니다.

⚡

초고속 병렬 레이스 (Fastest)

Cloudflare, Google, AdGuard 등 다중 글로벌 업스트림에 동시 질의하여 가장 빠르게 회신된 응답을 제공합니다.

🛡️

광고 및 트래킹 차단

모바일 인앱 광고, 유튜브 광고 도메인, 웹 트래커를 표준 NXDOMAIN 응답으로 차단하여 데이터와 배터리를 절약합니다.

🔒

DNS 암호화 (DoH)

HTTPS 표준 프로토콜로 DNS 패킷을 암호화하여 통신사(ISP) 및 공공 와이파이에서의 감청과 변조를 원천 방지합니다.

🌍

Cloudflare 엣지 캐싱

자주 조회되는 질의는 지리적으로 가장 가까운 글로벌 엣지 데이터센터에 캐싱되어 수 밀리초 내에 즉각 반환됩니다.

🎯

맞춤형 프로필 라우팅

URL 경로만으로 /dns-query/all, /dns-query/nonyt 등 원하는 차단 강도와 서버 모드를 선택할 수 있습니다.

📑

RFC 1035 표준 준수

엄격한 바이너리 파서와 표준 패킷 구조를 채택하여 모든 최신 운영체제 및 브라우저와 완벽하게 호환됩니다.

제공 프로필 안내

사용 환경에 맞는 프로필 URL을 선택하여 기기에 등록하세요.

기본 종합 차단 (All) 추천 (기본값)
모드: Fastest 경합

유튜브 광고, 주요 인앱 광고 및 웹 트래커를 전면 차단하고 Cloudflare Family/Security 업스트림을 경합합니다.

https://your-domain/dns-query
유튜브 제외 차단 (Non-YT) 우선순위 순차 모드
모드: Priority 순차

유튜브 접속은 정상 허용하면서 일반 광고/트래킹 도메인을 차단합니다. Cloudflare 및 Quad9 순차 Fallback으로 안정성을 높였습니다.

https://your-domain/dns-query/nonyt
AdGuard 업스트림 프로필 (No-Ad)
모드: Fastest 경합

기본 차단 목록과 함께 AdGuard Family & Default 업스트림 DNS를 통해 강력한 2중 필터링을 제공합니다.

https://your-domain/dns-query/noad
순수 DoH 프록시 (Raw / Default)
모드: Fastest 경합

도메인 차단 없이 Cloudflare(1.1.1.1)와 Google(8.8.8.8)을 경합하여 가장 빠른 암호화 DNS 조회만 수행합니다.

https://your-domain/dns-query/df

간편 설정 가이드

사용하시는 기기 또는 브라우저 탭을 선택하여 설정을 완료하세요.

1

Chrome / Edge / Whale 브라우저 설정 열기

브라우저 우측 상단 메뉴(⋮) -> 설정 -> 개인정보 보호 및 보안 -> 보안으로 이동합니다.

2

보안 DNS(DoH) 활성화

"보안 DNS 사용" 옵션을 켜고, "맞춤설정"을 선택합니다.

3

DoH URL 입력

입력란에 복사한 주소(https://your-domain/dns-query)를 붙여넣으면 즉시 적용됩니다.

1

안드로이드 Private DNS (DoT)와 DoH 안내

안드로이드 기본 설정의 "개인 DNS"는 DoT(TLS 853) 규격을 사용합니다. DoH(HTTPS)를 사용하시려면 브라우저 자체 보안 DNS 설정을 이용하시거나, Intra 또는 AdGuard 앱을 사용하세요.

2

앱(Intra 등) 설정

Google Play Store에서 Intra 앱을 설치한 후, 설정 -> DNS-over-HTTPS 서버 URL에 위 DoH 주소를 입력하고 활성화합니다.

1

Safari 및 브라우저

iOS 14+ 및 macOS Big Sur+부터 시스템 레벨에서 암호화된 DNS를 지원합니다. Chrome 또는 Firefox 브라우저 설정에서 DoH를 직접 활성화할 수도 있습니다.

2

DNS 프로파일(.mobileconfig) 적용

DoH 프로파일 생성기(예: dns.notjakob.com)를 이용하여 도메인을 등록한 프로파일을 생성 후 기기에 설치할 수 있습니다.

1

AdGuard Home 업스트림 등록

AdGuard Home 대시보드 -> 설정 -> DNS 설정 -> 업스트림 DNS 서버 목록에 다음 주소를 추가합니다:

https://your-domain/dns-query/all

2
