빠르고 안전한
프라이빗 DNS-over-HTTPS

광고와 트래커는 강력하게 차단하고, 다중 업스트림 병렬 쿼리로 가장 빠른 DNS 응답 속도를 경험하세요.

https://your-domain/dns-query

주요 기능

보안, 속도, 호환성을 모두 충족하는 차세대 DNS 솔루션입니다.

⚡

초고속 병렬 레이스 (Fastest)

Cloudflare, Google, AdGuard 등 다중 글로벌 업스트림에 동시 질의하여 가장 빠르게 회신된 응답을 제공합니다.

🛡️

광고 및 트래킹 차단

모바일 인앱 광고, 유튜브 광고 도메인, 웹 트래커를 표준 NXDOMAIN 응답으로 차단하여 데이터와 배터리를 절약합니다.

🔒

DNS 암호화 (DoH)

HTTPS 표준 프로토콜로 DNS 패킷을 암호화하여 통신사(ISP) 및 공공 와이파이에서의 감청과 변조를 원천 방지합니다.

🌍

Cloudflare 엣지 캐싱

자주 조회되는 질의는 지리적으로 가장 가까운 글로벌 엣지 데이터센터에 캐싱되어 수 밀리초 내에 즉각 반환됩니다.

🎯

맞춤형 프로필 라우팅

URL 경로만으로 /dns-query/all, /dns-query/nonyt 등 원하는 차단 강도와 서버 모드를 선택할 수 있습니다.

📑

RFC 1035 표준 준수

엄격한 바이너리 파서와 표준 패킷 구조를 채택하여 모든 최신 운영체제 및 브라우저와 완벽하게 호환됩니다.

제공 프로필 안내

설정된 모든 프로필이 자동으로 표시됩니다. 원하는 URL을 복사하여 기기에 등록하세요.

간편 설정 가이드

사용하시는 기기 또는 브라우저 탭을 선택하여 설정을 완료하세요.

1

Chrome / Edge / Whale 브라우저 설정 열기

브라우저 우측 상단 메뉴(⋮) -> 설정 -> 개인정보 보호 및 보안 -> 보안으로 이동합니다.

2

보안 DNS(DoH) 활성화

"보안 DNS 사용" 옵션을 켜고, "맞춤설정"을 선택합니다.

3

DoH URL 입력

입력란에 복사한 주소(https://your-domain/dns-query)를 붙여넣으면 즉시 적용됩니다.

1

안드로이드 Private DNS (DoT)와 DoH 안내

안드로이드 기본 "개인 DNS"는 DoT(TLS) 규격입니다. DoH(HTTPS)를 사용하시려면 브라우저 자체 보안 DNS를 이용하시거나, Intra 또는 AdGuard 앱을 사용하세요.

2

앱(Intra 등) 설정

Play Store에서 Intra 설치 후, 설정 -> DNS-over-HTTPS 서버 URL에 DoH 주소를 입력하고 활성화합니다.

1

Safari 및 브라우저

iOS 14+ 및 macOS Big Sur+부터 시스템 레벨에서 DoH를 지원합니다. Chrome / Firefox 브라우저 설정에서 DoH를 직접 활성화할 수도 있습니다.

2

DNS 프로파일(.mobileconfig) 적용

dns.notjakob.com 등의 도구를 이용해 도메인을 지정한 프로파일을 생성 후 기기에 설치할 수 있습니다.

1

AdGuard Home 업스트림 등록

AdGuard Home 대시보드 -> 설정 -> DNS 설정 -> 업스트림 DNS 서버 목록에 다음 주소를 추가합니다:

https://your-domain/dns-query/all

2

적용 및 테스트

하단의 [적용] 버튼을 누르면 내부 네트워크의 모든 기기 질의가 Yuhadns 프록시를 통해 고속 처리됩니다.
